# stevenwernke.com

Static site for Steven Wernke, Professor of Anthropology, Vanderbilt University.
Migrated from WordPress (BlueHost) in August 2026; look and content reproduce the
original Twenty Seventeen / Minimal 20/17 theme, including the rotating header banners.

Built by `wp-export/build_site.py` from a REST-API export of the original site.
Hosted on GitHub Pages (`.nojekyll` — plain static files, no build step).
